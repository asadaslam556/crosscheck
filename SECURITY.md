# Security

Crosscheck is a read-only analysis dashboard: no logins, no user data, and the API only answers `GET` requests over a fixed dataset. The Docker setup uses throwaway local credentials on purpose.

If you find a vulnerability anyway, please report it privately through [GitHub's vulnerability reporting](https://github.com/asadaslam556/crosscheck/security/advisories/new) rather than in a public issue. I'll reply within a week.

Fixes go into `main`; there are no older versions to patch.
